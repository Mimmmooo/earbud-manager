# Earbud Manager for macOS (planned)

Status: **Not implemented**. macOS Bluetooth transports and device permissions differ from Linux BlueZ, and the GNOME interface is not portable.

Plan: evaluate CoreBluetooth and any necessary Classic Bluetooth transport restrictions, choose a supported local control path, implement a native UI, verify real hardware operations, and package a signed app where feasible. No runnable macOS app is shipped.
