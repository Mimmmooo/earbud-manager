# Security and privacy

This utility talks to already paired Bluetooth devices. It does not require root privileges for normal use.

Do not share Bluetooth packet captures, device identifiers, human-readable device names or other personal details in public GitHub issues. When reporting a bug, redact such values first.

For a potentially sensitive vulnerability, do not include exploitation details in a public issue. Contact the repository maintainers through a private reporting channel if one is configured in the published GitHub repository. No security-contact email is embedded in this project.

There is no telemetry or network API in this release. Local custom names are saved in the user's own config directory.
